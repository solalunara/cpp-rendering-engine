<h1>C++ OpenGL Rendering Engine</h1>

This is an OpenGL rendering engine written in C++. My original attempt at this project was loosely based off <a href="https://learnopengl.com/">https://learnopengl.com/</a>, and since I've come back to it every so often to improve it as I've learned more about C++. This latest attempt used a lot of what I learned about the formal specifications of C++ at university, including the rule of 5 specifics and reliance on unique_ptr and shared_ptr to make pointer hierarchy explicit.
